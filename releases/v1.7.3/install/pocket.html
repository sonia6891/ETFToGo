把口袋圖示放到手機桌面

這個安裝檔內含口袋圖片，建立可點開《ETF 袋著走》的桌面捷徑。

下載桌面圖示安裝檔
  1. 在 Safari 點上面的按鈕，選「允許」。
  2. 開啟 iPhone「設定」→「已下載描述檔」。若沒有出現，前往「一般」→「VPN 與裝置管理」。
  3. 選「ETF 袋著走・桌面圖示」，檢查內容後點「安裝」。手機可能要求解鎖密碼；只在手機設定輸入。

安裝後回桌面，點口袋圖示開啟 App。

這是未簽署的 Web Clip 描述檔，僅新增一個可移除的桌面捷徑。不含裝置管理、憑證、VPN 或帳號設定。可在設定中移除本描述檔。

請先保留原有 App。若新入口沒有原有持有或配息紀錄，請從舊入口的「更多」匯出備份，再於新入口匯入。
