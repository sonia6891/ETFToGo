# ETF 袋著走｜原生 iPhone 工程 0.1.0

沿用既有 1.5.0 的名稱、藍白介面結構、口袋 Icon 與記帳資料格式，建立純 SwiftUI iPhone App。沒有 WebView、網站外殼或 Expo。原本 Railway 1.5.0 本次未修改。

**目前交付是原生原始碼工程，還不是可安裝 IPA。** Swift 核心已編譯並執行 25 項 XCTest；SwiftUI 通過語法解析，Xcode 工程通過結構檢查。尚未在 macOS／Xcode 編譯整個 App，尚未簽署、跑 iOS 模擬器或真機驗收。

## 工程內容

- 首頁：資產摘要、金額隱藏、功能入口與投資角色卡。
- 找 ETF：代碼／名稱搜尋、原有策略類型、三種投資角色篩選、收藏與最多三檔比較。
- 持有：新增、編輯、刪除，股／張換算、券商名稱、台幣成本及手動參考價。只對已填價格的部位估值。
- 股息月曆：月份切換、預估／公告／實收分開顯示，完整配息編輯。
- 試算：複利曲線、投入與領出分開、再投入、扣費及現金流目標；避免配息重複計入總報酬。
- 行情：直接向富果查詢最後成交價，顯示交易日期與錯誤。此原生版為按鈕手動更新，尚未移植舊版的 20 秒輪詢。
- 金鑰：iPhone Keychain，僅向 api.fugle.tw 傳送，拒絕 HTTP 重新導向，備份不含金鑰。
- 成分股：授權 API 查詢、JSON 匯入、來源與日期標示；持股透視只計算有資料的部位。
- 備份：支援舊版 ETF_CLASSIFIER v3、工具 v2 與原生版 JSON；驗證後才寫入。匯入取代前另存復原副本。
- 深色／淺色／跟隨系統。

券商自動同步仍未開放，與既有版一致。沒有新增下單、假帳戶、假行情、假歷史曲線或推播功能。API 權限與真實金鑰連線尚未實測。

## ETF 範圍

只收錄**台灣證交所上市 ETF**，不收錄上櫃或海外交易所掛牌商品；台灣上市、投資海外的 ETF 仍在範圍內。

內附官方名單出表日為 2026-10-14，共 272 個證券代碼，包含外幣交易級別，不能把代碼數直接稱為獨立基金數。來源：

https://openapi.twse.com.tw/v1/opendata/t187ap47_L

舊版線上篩選只有 88 檔國內股票 ETF；原生工程已移除這個限制。網路更新失敗時保留最後成功快照並顯示狀態。初次啟動可離線搜尋內附名單，持有和配息則預設空白，不預填測試資產。

## 三種投資角色

名稱固定為「存錢筒、印鈔機、老虎機」，App 名稱仍是《ETF 袋著走》。

| 角色 | 本版判斷 | 不應誤解為 |
| --- | --- | --- |
| 存錢筒 | 長期累積取向，依大盤／廣泛市場或短期政府債等公開線索初判 | 保本存款或完全低波動 |
| 印鈔機 | 收益取向候選，尚需含息報酬與回撤資料核驗 | 高配息就等於穩定獲利 |
| 老虎機 | 槓桿、反向、期貨、主題集中或較高信用／利率敏感度等初判 | 保證高報酬 |

目前 272 個代碼中：存錢筒 14、印鈔機候選 43、老虎機初判 119、待核驗 96。「待核驗」是證據不足狀態，不是第四種投資角色。逐檔結果與理由在 `docs/classification.csv`。

**尚未取得足夠的歷史含息報酬，沒有任何一檔被宣稱已證實能持續穩定獲利。** 分類以公開名稱、基金類型、指數線索作為可解釋的第一版規則，不是正式研究評級；應在投信公開說明書、實際持倉及歷史資料核驗後再改為確認狀態。

## 用 Xcode 開啟

1. 在 Mac 安裝 Xcode 16 或更新版本，解壓縮後開啟 `ETFToGo.xcodeproj`。
2. 選取共享 Scheme `ETFToGo`。模擬器可先不設定 Apple Team。
3. 點 Run 建置。最低 iOS 17，iPhone 直向介面。
4. 真機安裝：在 Signing & Capabilities 選擇你自己的 Apple Team；確認 `com.sonia.etftogo` 的 Bundle ID 是否適用，再連接 iPhone 並簽署執行。
5. TestFlight：仍需 App Store Connect 的此 App 紀錄、對應 Bundle ID、簽署及 Archive 上傳。這些尚未執行。

工程沒有第三方套件，使用 Apple SwiftUI、Charts、Security 與 Foundation。`Package.swift` 是可獨立測試的核心，不是 iPhone App 的替代入口。

## 驗證與 GitHub

```sh
swift test
bash scripts/build-ios.sh
```

已附 GitHub Actions 工作流程，會執行核心測試及 iPhone 模擬器／未簽署裝置編譯；**工作流程目前尚未在 GitHub 執行**。模擬器產物不是 iPhone 安裝檔，未簽署裝置編譯也不代表可安裝。

本次查核的可存取 GitHub 倉庫沒有 ETF 專用倉庫，因此尚未推送。需要指定此專案的 GitHub 倉庫，才能接上遠端 macOS 編譯；不會把工程放進其他 App 的倉庫。

本次 Linux 環境以 Swift 6.2.3 直接編譯核心模組與 XCTest 執行器，25 項測試全部通過。SwiftPM 在此容器啟動編譯工作時出現環境執行錯誤，所以不將它標記為 `swift test` 成功。可用 `scripts/test-core-direct.sh` 重現直接 XCTest 測試；測試日誌及結構檢查位於 `docs/`。
